# 📚 תיקיית מסמכים

תיקייה זו מכילה את כל המסמכים החשובים לפיתוח ולהבנת הפרויקט.

## 📄 מסמכים זמינים

### 1. [ARCHITECTURE.md](ARCHITECTURE.md)

**מסמך ארכיטקטוני מלא**

מכיל:

- 🏛️ עקרונות ליבה (Separation of Concerns, Single Source of Truth)
- 📐 מבנה הפרויקט המפורט
- 🔧 תיאור שכבת הליבה (Core Logic)
- 🎨 תיאור שכבת התצוגה (UI Layer)
- ✅ שיקולי פיתוח ובדיקות

**קרא את זה לפני תחילת העבודה** כדי להבין את החזון והעקרונות.

### 2. [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md)

**הוראות בנייה מפורטות - 7 שלבים (0-6)**

מכיל:

- 📋 עקרונות כלליים לכל השלבים
- 🔧 שלב 0: הכנה ותשתית
- 📊 שלב 1: חוזה טיפוסים ו-Graph API
- 🧮 שלב 2: אלגוריתמים גרפיים
- 🎨 שלב 3: רכיבי UI בסיסיים
- 🔗 שלב 4: חיבור אינטגרציה וניהול state
- 🧪 שלב 5: בדיקות אינטגרציה וביצועים
- 📝 שלב 6: דוקומנטציה ושחרור

**כל סוכן/מפתח חייב לקרוא את השלב הספציפי שלו לפני העבודה.**

כל שלב כולל:

- ✅ קריטריוני קבלה ברורים
- 🛡️ הוראות בטיחות למניעת לולאות אין סופיות
- ⏱️ הערכת זמן
- 📝 דוגמאות קוד מלאות

## 🎯 איך להשתמש במסמכים?

### למפתח חדש בפרויקט:

1. קרא [ARCHITECTURE.md](ARCHITECTURE.md) להבנת המבנה הכללי
2. עבור ל-[BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md) לשלב שאתה עובד עליו
3. עקוב אחר הקריטריונים והוראות הבטיחות

### לסוכן AI:

- בכל פעם שמתחיל עבודה על שלב, קרא את השלב הספציפי ב-[BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md)
- וודא עמידה בכל קריטריוני הקבלה
- שים לב מיוחד להוראות הבטיחות

### למנהל פרויקט:

- השתמש ב-[BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md) למעקב אחר התקדמות
- כל שלב עצמאי עם תוצרים ברורים
- ניתן להקצות שלבים שונים לסוכנים שונים במקביל (3-6 אחרי שלבים 0-2)
